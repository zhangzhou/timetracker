# 时间追踪 Android 部署指南

## 推荐方案：GitHub Actions 自动构建（无需安装开发环境）

### 步骤

1. **注册 GitHub 账号**（已有则跳过）
   - 访问 https://github.com/signup

2. **创建新仓库**
   - 点击右上角 `+` → `New repository`
   - 仓库名填 `TimeTracker`
   - 选择 `Public`（免费）
   - 点击 `Create repository`

3. **上传项目代码**
   - 解压 `TimeTrackerAndroid.zip` 到本地文件夹
   - 确认包含 `build.gradle`、`settings.gradle`、`app/` 等文件
   - 在仓库页面点击 `uploading an existing file`
   - 拖拽所有文件到上传区域（保持目录结构）
   - 点击 `Commit changes`

4. **触发自动构建**
   - 上传完成后，点击仓库顶部 `Actions` 标签
   - 等待约 3-5 分钟，工作流 `Build APK` 会自动运行
   - 完成后点击该工作流 → `Artifacts` → 下载 `TimeTracker-APK`

5. **安装到手机**
   - 将下载的 APK 传到手机（微信/QQ/数据线均可）
   - 在手机上点击 APK 安装
   - 若提示"未知来源"，前往设置允许即可

## 备选方案：Android Studio 本地构建

### 环境准备

| 软件 | 下载地址 |
|------|---------|
| Android Studio | https://developer.android.com/studio |

### 编译步骤

1. **解压项目**
   ```bash
   unzip TimeTrackerAndroid.zip -d TimeTracker
   ```

2. **打开项目**
   - 启动 Android Studio → `Open` → 选中 `TimeTracker` 文件夹
   - 等待 Gradle Sync（首次约 5-10 分钟自动下载依赖）

3. **连接手机**
   - 手机设置 → 关于手机 → 连续点击"版本号"7次开启开发者模式
   - 返回设置 → 系统 → 开发者选项 → 开启 **USB 调试**
   - 用数据线连接电脑，手机弹窗选择"允许 USB 调试"

4. **编译并安装**
   - Android Studio 顶部工具栏选择你的手机设备
   - 点击绿色播放按钮 `▶ Run 'app'`
   - 等待编译（约 2-3 分钟），自动安装并启动

## 手机端必要设置

### 1. 允许安装未知应用
安装 APK 时系统会拦截，点击"设置"→ 允许该来源。

### 2. 通知权限（Android 13+）
首次启动 APP 会弹窗请求通知权限，务必点击**允许**。

### 3. 精确闹钟权限（Android 12+，关键！）
设置 → 应用 → 时间追踪 → 权限 → **允许设置闹钟和提醒**
> 此权限决定提醒是否准时，不开启则后台提醒可能延迟。

### 4. 电池优化白名单（各品牌手机）

| 品牌 | 路径 |
|------|------|
| **华为/荣耀** | 设置 → 电池 → 启动管理 → 时间追踪 → 手动管理 → 允许自启动 + 允许后台活动 |
| **小米/Redmi** | 设置 → 省电与电池 → 右上角设置 → 应用智能省电 → 时间追踪 → 无限制 |
| **OPPO/一加/realme** | 设置 → 电池 → 应用耗电管理 → 时间追踪 → 允许完全后台行为 |
| **vivo/iQOO** | 设置 → 电池 → 后台耗电管理 → 时间追踪 → 允许后台高耗电 |
| **三星** | 设置 → 电池 → 后台使用限制 → 不优化应用 → 添加时间追踪 |
| **Google Pixel** | 设置 → 应用 → 时间追踪 → 电池 → 无限制 |

> ⚠️ **重要**：如果不加入电池白名单，系统会在几小时后杀死 APP 后台进程，导致提醒失效。

## 首次使用流程

1. 打开 APP，授予**通知权限**
2. 进入"设置"页，选择提醒间隔（默认 30 分钟）
3. 开启"启用提醒"开关
4. 系统会弹出"允许设置闹钟"的跳转提示，点击前往设置并开启
5. 返回 APP，此时后台已设置精准闹钟
6. 到时间点时，即使手机锁屏也会弹出强提醒通知

## 常见问题

**Q: 提醒不准时或没响？**
A: 检查三点：①通知权限 ②精确闹钟权限 ③电池优化白名单

**Q: 图表不显示？**
A: 首次打开需要联网加载 Chart.js（约 200KB）。若完全无网络，图表区域会空白但不影响记录功能。

**Q: 数据会丢失吗？**
A: 数据保存在 APP 私有存储中，卸载 APP 会丢失。请定期在设置页导出 JSON 备份。
